# Análise de Acidentes de Trânsito no Brooklyn e Staten Island

Este projeto tem como objetivo analisar e visualizar dados de acidentes de trânsito nos bairros do Brooklyn e Staten Island, em Nova York. Utilizando grafos de ruas e técnicas de análise de redes, o projeto explora padrões e distribuições de acidentes para apoiar estudos urbanos e de segurança viária.
